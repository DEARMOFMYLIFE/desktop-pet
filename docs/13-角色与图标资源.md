## 1. 为什么选这套

前两版角色分别使用程序化 PIL 绘制和像素画，观感不符合“可爱、现代、非像素”的要求。
Cute Girl 是扁平矢量、粉彩配色的 Q 版角色：

- 大头、大蓝眼、红发、青绿连衣裙
- 原生 **Idle / Walk / Run / Jump / Dead** 五组高清逐帧动画（416×454 起）
- 原生动画就是全身运动：头发、身体、双臂、双腿一起动
- CC0，可商用、可修改、无需署名

用户确认的预览：

- `docs/previews/cute-girl-preview.gif`
- `docs/previews/cute-girl-preview.png`
- `docs/previews/cute-girl-idle-large.png`

## 3. 11 个动作的来源

| 状态 | 来源 | 循环 | 帧数 / fps |
|---|---|---|---|
| `idle` | 原生 `Idle`（全帧 + 眨眼） | 是 | 16 / 10 |
| `walk` | 原生 `Walk`（全帧） | 是 | 20 / 14 |
| `sit` | 自定义：坐姿 + 软垫 + 呼吸浮动 | 是 | 6 / 4 |
| `sleep` | 原生 `Dead` 末段躺姿 + Zzz + 微动 | 是 | 8 / 4 |
| `focus` | 自定义：坐姿 + 打开的书 + 呼吸 | 是 | 6 / 4 |
| `break` | 原生 `Jump` 慢速循环（伸懒腰/轻跳） | 是 | 16 / 8 |
| `celebrate` | 原生 `Jump` + 星星 | 否 | 16 / 12 |
| `drag` | 原生 `Jump` 空中段 + 左右摆动 | 是 | 10 / 10 |
| `react` | 原生 `Jump` 起跳段 + 感叹号 | 否 | 10 / 14 |
| `remind` | 原生 `Jump` 挥手段 + 动作弧线 | 是 | 10 / 8 |
| `droop` | 自定义：前倾、下沉、蓝色汗滴 | 是 | 6 / 4 |

- `sit` / `focus`：从 Idle 帧中移除白色腿部，整体下移，坐在软垫上；软垫颜色取裙子色相的 +0.25 类比色，避免与头发/裙子撞色。
- `sleep`：Dead 动画最后 8 帧是闭眼侧躺，直接在头顶绘制漂移的 Zzz。
- `break` / `celebrate` / `drag` / `react` / `remind`：复用原生 Jump 的不同段落，并叠加不同装饰，保证全身运动。
- `idle` / `sit` / `focus` / `droop` 各加入一帧眨眼，避免脸部长时间完全静止。
- 所有状态共用同一脚底锚点和缩放，切换状态不跳位。

## 4. 资源规格

- 单帧：**200×200** 透明 WebP（`quality=90, method=6`）
- 每状态 6–20 帧横向排列
- `manifest.json`：`version: 4`、`frameSize: [200,200]`、`anchor: [0.5,1.0]`
- 每个皮肤：11 个 `.webp` + `manifest.json` + `preview.png`（256×256）
- 无 PNG 回退：目标平台 WebView 均支持 WebP；`useSpriteAnimation` 已支持无 fallback
- 16 套皮肤共 208 个文件，约 13 MB

裁剪/合成方式：

- Idle / Walk / Jump：以源画布底部为地面，480×480 窗口居中，缩放到 200×200
- Dead：以躺姿内容中心为水平中心、源画布底部为地面，同比例缩放
- 每帧底部绘制柔和阴影，保证在透明桌面上有落点

## 5. 皮肤切换无残影

1. **启动预加载**：16 套皮肤的 manifest + idle sheet 全部预取；当前皮肤 11 个状态后台预取
2. **模块级缓存**：manifest、已加载图片、加载中图片去重
3. **切换策略**：
   - 新皮肤 manifest 已缓存时立即切换
   - 目标状态图未就绪时先显示新皮肤的 idle，加载完成后无缝切到目标状态
   - 任何情况下都不会把旧皮肤留在 DOM 上
4. 渲染使用 `canvas` 逐帧 `clearRect` + `drawImage`；切状态/皮肤先清空整张画布，新图 decode 后再绘制，杜绝旧帧残留
   - 移除 `WEBKIT_DISABLE_COMPOSITING_MODE=1`：透明窗口 + 禁用 WebKit 合成会导致局部重绘不干净，是残影/局部不动的根因之一
   - 画布覆盖整个宠物窗口，每帧整面清空，避免窗口只重绘局部区域
   - 动画期间不触发 React 重渲染

## 6. 图标与品牌图

应用图标不再使用角色头像，改为**独立的原创扁平图标主题**：

- `clock`（默认推荐，契合计时/专注）
- `star` / `moon` / `coffee` / `sun` / `leaf` / `heart` / `cloud` / `book` / `flower`
- 设置 → 外观 → 应用图标可切换
- 支持导入自定义 PNG 图标，名称会 trim 并做重复校验
- 切换会同步：托盘图标、宠物/设置/气泡/引导窗口图标、设置页与关于页品牌图、
  Linux 应用菜单、桌面快捷方式图标与显示名称
- 当前图标写入 `~/.local/share/yuzu/app-icon.png`
- 默认打包图标：`backend/icons/icon.png`、`512x512.png`、`128x128@2x.png`、`128x128.png`、`32x32.png`、`icon.ico`、`icon.icns`
- 托盘：`backend/icons/tray.png` / `tray-template.png`
- 品牌：`frontend/public/brand/icon-{clock,star,moon,coffee,sun,leaf,heart,cloud,book,flower}.png`
- 生成脚本：`scripts/icon-themes.py`
