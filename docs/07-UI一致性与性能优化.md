## 1. 样式复用审计

| 类 | 用途 |
|---|---|
| `.card` / `.card-title` | 设置页与内容卡片 |
| `.row` / `.row-label` | 设置行 |
| `.btn` / `.btn-primary` / `.btn-ghost` / `.btn-danger` | 所有按钮 |

| `.notice` | 提示条 |
| `.badge` | 状态标签 |
| `.empty` | 空状态 |

### 复用组件

- `SettingsCard` → `.card`
- `SettingRow` → `.row` + `.row-label`
- `Notice` → `.notice`
- `SettingsSidebar` / `SettingsHeader` → 设置页布局
- `BubbleShell` → 气泡/提醒弹窗 Header
- `OnboardingHeader` / `OnboardingFooter` → 引导布局
- `ConfirmDialog` → 所有破坏性确认

- 删除未使用样式：`.section-heading`、`.stat-grid`、`.stat`、`.skin-row`、`.skin-preview`、`.bubble-m0`、`.card-desc`、`.badge-muted`。
- 新增样式仅限现有语义类不足时；优先通过 Tailwind `@apply` 与 tokens 组合。

## 2. 一致性检查与修正

| 检查项 | 发现 | 修正 |
|---|---|---|
| 圆角 | 品牌块、气泡关闭按钮、Tab 导航存在 10/12/16/9px 混用 | 统一到 `--radius-sm/md/lg/xl` token |

## 3. 性能分析

### 3.1 组件重渲染

| 问题 | 处理 |
|---|---|
| 宠物窗 hint/settings 变化导致 `PetStage` 重渲染 | `memo(PetStage)` + `useCallback` 稳定 6 个事件回调 |
| 设置保存时侧边栏/Header 跟随重渲染 | `memo(SettingsSidebar)`、`memo(SettingsHeader)` |
| 待办表单输入导致列表/工具栏重渲染 | `memo(TodoList)`、`memo(TodoToolbar)` + `useCallback` 稳定回调 |
| 气泡计时每秒更新 | 属于必要更新；仅 `TimerCard` 局部更新 |
| 统计/待办数据 | 查询结果驱动；`useMemo` 过滤可见待办 |

### 3.2 大列表

- 统计柱状图最多 30 天，不需要虚拟滚动。
- 待办列表为用户手工录入，通常为个位数到几十条；暂不引入虚拟滚动依赖。
- 对 `.todo-row` 增加 `content-visibility: auto` 与 `contain-intrinsic-size`，让浏览器跳过屏幕外行布局/绘制；如后续待办达到数百条，再引入虚拟列表。

### 3.3 图片 / 资源

| 资源 | 处理 |
|---|---|
| 角色预览 `preview.png` | `loading="lazy"` + `decoding="async"` |
| 品牌 mascot.png | `decoding="async"` |
| 角色动作序列帧 | 改为 DOM background sprite；manifest 按皮肤加载，状态切换只替换当前背景图 |
| 角色渲染 | 不再使用 Canvas 逐帧叠加；用 CSS background-position 显示单帧，彻底避免透明帧残影；`reduceMotion` 时停在首帧 |

### 3.4 定时器 / 监听器

已检查并修复：

- `PetWindow` 点击后的 1.6s 复位定时器与 0.9s hint 定时器：使用 ref 保存，卸载时清理，重复点击先清旧定时器。
- `PetStage` 单击延迟 300ms 定时器：卸载时清理。
- `useSettingsWindow` Toast 1.8s 定时器：已有清理。
- `useBubbleWindow` 的 `timer:changed` / `settings:changed` / `reminder:fired`、`focus`、`visibilitychange`：已有清理。
- `usePetWindow` 的 `settings:changed` / `pet:click_through` / `pet:changed`、`focus`、`visibilitychange`：已有清理。
- 项目无 WebSocket、无长连接；Rust 端 tokio ticker 随应用进程生命周期存在。
