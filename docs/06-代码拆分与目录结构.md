# 06 · 代码拆分与目录结构

> 日期：2026-11-09
> 范围：前端 React/TypeScript 与后端 Rust/Tauri 全量重构
> 目标：所有页面/业务文件 ≤ 200 行；重复 UI 抽公共组件；业务逻辑进 hooks；类型集中到 types/。

---

## 1. 拆分原则

1. **页面 ≤ 200 行**：页面只保留布局与子组件组合，超过 200 行必须拆分。
2. **重复 UI 抽组件**：同一结构出现 2 次以上即抽取，保持原有 className，避免样式回归。
3. **业务逻辑进 hooks**：数据加载、事件订阅、IPC 调用、表单状态放入 `hooks/`。
4. **类型集中到 types/**：跨模块 DTO、领域类型、页面共享 Props 统一放入 `types/`。
5. **后端按域拆分**：`commands / storage / timer / pet / reminders / windows / types` 各自独立。
6. **对外契约不变**：IPC 命令名、SQLite schema、事件名、CSS 类名、序列化字段全部保持原样。

## 4. 不变量

- IPC 命令名：`app_bootstrap`、`timer_start`、`todo_create` 等全部保持不变。
- 前端 `api` 对象方法签名保持不变；`lib/ipc` 目录仍可 `from '../../lib/ipc'` 导入。
- 事件名：`timer:changed`、`timer:completed`、`pet:changed`、`settings:changed`、`reminder:fired` 不变。
- 数据库表、字段、schema 不变；`schema.sql` 路径改为 `storage/mod.rs` 相对引用。
- CSS 类名不变；拆分组件复用原 class。
- 设置默认值、计时状态机、提醒调度、待办提醒、统计 SQL 不变。

## 5. UI 基础与组件复用

- **Tailwind CSS v3 + PostCSS**：`frontend/tailwind.config.js`、`frontend/postcss.config.js`。
- 设计 Token 保留在 `styles/tokens.css`，Tailwind 主题映射到 `--bg` / `--surface` / `--accent` 等变量。
- 语义类（`.card`、`.btn`、`.settings-shell`、`.bubble-card` 等）通过 `@apply` 实现，页面继续复用原类名，避免视觉回归。
- 图标统一使用 `lucide-react`，覆盖锁、关闭、检查、闹钟、键盘、灯泡、箭头等；界面中不再出现 emoji 图标。
- 布局组件：
  - `components/layout/SettingsSidebar.tsx`
  - `components/layout/SettingsHeader.tsx`
  - `windows/bubble/components/BubbleShell.tsx`
  - `windows/onboarding/OnboardingHeader.tsx` / `OnboardingFooter.tsx`
- 数据动作统一经 `lib/ipc/api.ts`；页面/面板通过 hooks 调用，不直接 `invoke`。
- TypeScript 保持 `strict: true`，源码中无 `any`。

## 7. 后续新增代码约束

1. 新增页面超过 200 行：先拆子组件，再提交。
2. 新增同类卡片/行/提示条：复用 `components/settings` 或 `components/ui`。
3. 新增 IPC：类型放 `types/`，调用放 `lib/ipc/api.ts`，mock 放 `lib/ipc/mock/`。
4. 新增流程：先写 `hooks/useXxx.ts`，页面只消费 hook。
5. 后端新增命令：按域放入 `commands/`；数据库访问放 `storage/`；共享 DTO 放 `types/`。
