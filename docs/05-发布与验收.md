## 2. 本地打包

### 2.1 前置

- Node.js 20+、Rust stable、Tauri 2 系统依赖（见 `docs/04` §10.1）。
- Linux 需要 `libwebkit2gtk-4.1-dev`、`libayatana-appindicator3-dev`、`librsvg2-dev`。
- macOS 需要 Xcode Command Line Tools。
- Windows 需要 MSVC Build Tools + WebView2 Runtime。

### 2.2 一键脚本

```bash
# macOS / Linux
./scripts/build-release.sh

# Windows PowerShell
./scripts/build-release.ps1
```

脚本依次执行：

1. `npm run lint`
2. `npm test`
3. `npm run build`
4. `npm run tauri -- build`
5. `node scripts/checksums.mjs` → `SHA256SUMS.txt`（CI 按平台生成 `SHA256SUMS-*.txt`）

> 当前开发机 Ubuntu 20.04 只有 WebKitGTK 4.0，无法执行第 4 步；请使用 Ubuntu 22.04+ / 22.04 容器 / GitHub Actions。

### 2.3 单独命令

```bash
npm ci
npm run tauri -- build
node scripts/checksums.mjs
```

Tauri 会自动构建前端（`beforeBuildCommand`）并按当前平台生成可用目标；`bundle.targets = "all"`。

## 3. CI 发布流程

### 3.1 日常检查

`.github/workflows/ci.yml`：

- Ubuntu 22.04 / macOS 14 / Windows
- `npm ci` → `lint` → `test` → `build`
- `cargo fmt` → `clippy --all-targets -D warnings` → `cargo test`

### 3.2 打标签发布

`.github/workflows/release.yml`：

```bash
git tag v0.1.0
git push origin v0.1.0
```

- 矩阵：
  - Ubuntu 22.04（AppImage/deb）
  - macOS 13 x64（x86_64-apple-darwin）
  - macOS 14 arm64（aarch64-apple-darwin）
  - Windows latest（NSIS/MSI）
- `tauri-apps/tauri-action@v0` 构建并创建 **draft release**
- `scripts/checksums.mjs` 生成 `SHA256SUMS-<os>-<target>.txt` 并上传到同一 release
- 进入 GitHub Release 检查产物后手动发布

### 3.3 签名状态

| 平台 | 当前 | 后续 |
|---|---|---|
| Windows | 未签名 | 购买代码签名证书；配置 `bundle.windows.certificateThumbprint` / `signCommand` |
| macOS | 未签名、未公证 | Apple Developer ID + `notarytool`；配置 `bundle.macOS.signingIdentity` |
| Linux | 无需签名 | 提供 `SHA256SUMS.txt` |

未签名包会触发 Windows SmartScreen / macOS Gatekeeper 提示；README 与 Release 说明需给出“仍要打开”的步骤。

## 6. 已知限制 / 发布说明

1. **当前开发机 Ubuntu 20.04** 只有 WebKitGTK 4.0；Tauri 2 需要 4.1（Ubuntu 22.04+），因此本机未生成真实安装包。
2. 安装包**未签名**：Windows SmartScreen、macOS Gatekeeper 会提示；Release Notes 需附操作说明。
3. Linux Wayland 下透明窗口/点击穿透可能降级；X11 为主验证环境。
4. 无自动更新；用户需手动下载新版本。
5. 数据全部本地；卸载不会自动删除用户数据目录，需在“关于 → 清除全部数据”或手动删除。
6. 角色来自 Cute Girl - Free Sprites（pzUH，CC0 1.0）；应用图标为项目原创（MIT），发布时保留 `LICENSES.md`。
