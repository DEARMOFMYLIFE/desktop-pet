## 2. 本地打包

### 2.1 前置

- Node.js 20+、Rust stable、Tauri 2 系统依赖（见 `docs/04` §10.1）。
- Linux 需要 `libwebkit2gtk-4.1-dev`、`libayatana-appindicator3-dev`、`librsvg2-dev`。
- macOS 需要 Xcode Command Line Tools。
- Windows 需要 MSVC Build Tools + WebView2 Runtime。

### 2.2 本地构建

```bash
npm install
npm run lint
npm test
npm run build
npm run tauri -- build
```

Tauri 会自动构建前端（`beforeBuildCommand`）并按当前平台生成可用目标；`bundle.targets = "all"`。

需要校验产物时，在发布目录执行系统自带命令：

```bash
# macOS / Linux
shasum -a 256 <artifact>

# Windows PowerShell
Get-FileHash <artifact> -Algorithm SHA256
```

> 构建、签名与验收均在本地环境完成。

### 2.3 签名状态

| 平台 | 当前 | 后续 |
|---|---|---|
| Windows | 未签名 | 购买代码签名证书；配置 `bundle.windows.certificateThumbprint` / `signCommand` |
| macOS | 未签名、未公证 | Apple Developer ID + `notarytool`；配置 `bundle.macOS.signingIdentity` |
| Linux | 无需签名 | 提供 `SHA256SUMS.txt` |

未签名包会触发 Windows SmartScreen / macOS Gatekeeper 提示；README 与 Release 说明需给出“仍要打开”的步骤。

## 5. 已知限制 / 发布说明

1. 构建与验收请在本地或目标机器上完成。
2. 安装包**未签名**：Windows SmartScreen、macOS Gatekeeper 会提示；Release Notes 需附操作说明。
3. Linux Wayland 下透明窗口/点击穿透可能降级；X11 为主验证环境。
4. 无自动更新；用户需手动下载新版本。
5. 数据全部本地；卸载不会自动删除用户数据目录，需在“关于 → 清除全部数据”或手动删除。
6. 角色来自 Cute Girl - Free Sprites（pzUH，CC0 1.0）；应用图标为项目原创（MIT），发布时保留 `LICENSES.md`。

## 6. 回滚

- 发布目录保留旧版本安装包与 `SHA256SUMS-*.txt`。
- 应用无数据库破坏性迁移（v1 初始版本）；回滚只需安装旧版本。
- 如发布包异常：将 draft release 标记为 pre-release 或删除，重新打标签构建。
