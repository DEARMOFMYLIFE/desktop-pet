## 1. 背景与目标

### 1.1 背景

桌面是大多数人一天中停留最久的数字空间，但主流效率工具要么是冷冰冰的列表，要么需要主动打开；桌面宠物则通常只有装饰性，无法形成长期使用理由。

小驻把两者结合：**一个常驻屏幕边缘、有生命感的小人，承载番茄钟、计时器、健康提醒、待办和专注统计**。用户不需要额外打开网页或应用，所有操作都能从托盘、右键菜单、快捷键或小人本身完成。

### 1.2 产品定位

> **常驻屏幕边缘的 2D 陪伴小人 + 轻量专注助手。**

三个关键词：

- **陪伴**：待机、走动、睡觉、被戳会反应，有心情和精力。
- **轻量**：不抢焦点、不挡内容、不制造焦虑；点击穿透一键“摸鱼”。
- **闭环**：专注 → 休息 → 提醒 → 待办 → 统计，形成可坚持的节奏。

### 1.3 产品目标

| 目标 | 说明 |
|---|---|
| G1 陪伴感 | 小人有稳定的存在感与可预期的行为，不打扰 |
| G2 专注闭环 | 番茄钟从开始到完成到休息，全流程可在小人附近完成 |
| G3 健康提醒 | 喝水、久坐、护眼三类提醒可配置、可稍后 |
| G4 轻任务 | 单层待办足够记录日常小事，不引入项目管理负担 |
| G5 可回顾 | 今日/7 天/30 天统计让用户看到积累 |
| G6 三端一致 | Windows/macOS/Linux 功能与交互一致，允许平台外观差异 |
| G7 离线可信 | 无账号、无网络、数据本地、可清除 |

### 1.4 非目标

- AI 对话、语音、大模型接入；
- 全桌面自由走动、攀爬窗口、全屏覆盖；
- 账号、云同步、社交、排行榜；
- Live2D / 3D / 角色编辑器 / 用户上传素材；
- 项目、标签、子任务、看板、协作；
- 自动更新、内购、付费；
- 音效、BGM、语音包；
- 移动端 / Web 版。

### 1.5 成功指标

产品完全离线、无遥测，以下指标用于**人工验收与用户访谈**，不在应用内上报：

| 指标 | 目标 |
|---|---|
| 首次启动到第一次开始专注 | ≤ 3 分钟 |
| 首次启动完成引导率 | ≥ 80%（人工观察） |
| 一周内至少完成 5 轮番茄钟的用户 | ≥ 50%（试用样本） |
| 点击穿透使用率 | 作为“是否打扰”的负向信号，持续观察 |
| 崩溃/数据丢失 | 0 起 |
| 三端冒烟通过 | 100% |

### 1.6 技术选型摘要

| 层 | 选型 | 说明 |
|---|---|---|

## 2. 用户与场景

### 2.1 目标用户

| 用户 | 特征 | 核心诉求 |
|---|---|---|
| 学生 / 自习者 | 长时间坐在电脑前，需要专注节奏 | 番茄钟、陪伴、统计 |
| 远程办公 / 程序员 | 久坐、容易忘记休息、桌面上常开很多窗口 | 健康提醒、点击穿透、快捷键 |
| 自由职业 / 创作者 | 需要轻量待办与专注记录 | 待办、计时器、统计 |
| 桌面美化爱好者 | 喜欢可爱角色与个性化 | 小人行为、尺寸、位置、皮肤 |

### 2.2 角色定义

本产品是**单用户本地应用**，不区分权限角色。文档中的“用户”均指本机使用者。

### 2.3 核心场景

1. **开始工作**：右键小人 → 开始专注 → 小人进入工作动画，气泡显示倒计时。
2. **专注被打断**：点击穿透 → 小人半透明不挡操作；需要控制时用快捷键或托盘恢复。
3. **久坐提醒**：系统通知 + 小人招手，用户选择“5 分钟后提醒”或“知道了”。
4. **记录小事**：设置窗口 → 待办 → 添加“给客户回邮件”，到点提醒。
5. **回顾一天**：设置窗口 → 统计 → 看到今日 4 轮、100 分钟。
6. **下班退出**：托盘 → 退出 → 确认；或在设置中关闭开机自启。

## 4. 功能需求

> 约定：`MUST` = P0 必须；`SHOULD` = P1 应该；`MAY` = 可选。
> 所有时间均为本地时区；所有长度单位若无特别说明均为逻辑像素（logical px）。

### 4.1 宠物窗口与行为（FR-PET）

#### FR-PET-01 窗口形态（MUST）

- 宠物窗为**无边框、透明背景、始终置顶、不显示在任务栏/程序坞**的小窗口。
- 窗口尺寸 = 角色尺寸 + 32px 透明内边距；默认 M 码 144px，窗口 176×176。
- 窗口不获取焦点（点击不激活应用），除非打开右键菜单或设置。
- 窗口阴影关闭；透明区域不显示任何底色。
- macOS：显示在所有桌面空间（Spaces）；Windows：置顶层级高于普通窗口；Linux：X11 下置顶。

**验收**：三端启动后只看到小人，没有白底/黑底/边框；切换桌面或全屏应用时行为符合平台预期。

#### FR-PET-02 默认位置与拖拽（MUST）

- 首次启动默认位于**主屏工作区右下角**，距右、下边缘各 24px。
- 按住左键可拖动；拖动时播放 `drag` 动画，窗口跟随光标。
- 松开后：若距任意屏幕边缘 ≤ 48px，吸附到该边缘；否则停在当前位置。
- 位置限制在当前显示器工作区内，不允许完全拖出屏幕。
- 位置按“显示器 + 归一化坐标”持久化；显示器断开时回退到主屏并夹取到可见区域。
- 改变角色尺寸后，以角色底部中心为锚点重新贴边。

**验收**：拖到屏幕外松手会被拉回；重启后位置恢复；拔掉副屏后小人出现在主屏可见区域。

#### FR-PET-03 动画状态机（MUST）

状态集合：

| 状态 | 触发 | 循环 | 说明 |
|---|---|---|---|
| `idle` | 默认 | 是 | 呼吸、眨眼 |
| `walk` | 自主行为 | 是 | 沿屏幕边缘移动 |
| `sit` | 自主行为 | 是 | 坐在边缘 |
| `sleep` | 长时间无交互 | 是 | 睡觉，Zzz |
| `focus` | 番茄钟专注中 | 是 | 工作/敲键盘 |
| `break` | 短休/长休中 | 是 | 伸懒腰/喝水 |
| `celebrate` | 完成一轮 | 否 | 庆祝，3 秒后回到目标状态 |
| `drag` | 拖拽中 | 是 | 被拎起 |
| `react` | 单击/互动 | 否 | 惊讶/开心，1.5 秒 |
| `remind` | 健康/待办提醒 | 否 | 招手，3 秒 |
| `droop` | 心情 < 30 的 idle 变体 | 是 | 蔫蔫的 |

**优先级**：`drag` > `react` / `celebrate` / `remind` > `focus` / `break` > `sleep` / `sit` / `walk` > `idle`。

**规则**：

- 计时器状态变化时，宠物状态必须同步：专注 → `focus`；短休/长休 → `break`；完成 → `celebrate` 后进入下一阶段。
- 点击穿透开启时，仍播放动画，但降低不透明度到 60%。
- 系统“减少动态效果”开启时，禁用自主走动与大幅动画，只保留 `idle` 轻微呼吸。

**验收**：任意状态切换无闪烁、无卡帧；计时开始/暂停/结束后 300ms 内宠物状态正确。

#### FR-PET-04 自主行为（MUST）

- 无计时、无交互、非拖拽时，每 **20–60 秒**随机选择一次行为：
  - 45% 待机 / 环顾；
  - 25% 沿当前边缘走 40–160px；
  - 15% 坐下；
  - 10% 伸懒腰（`react` 变体）；
  - 5% 睡觉（仅当连续无交互 ≥ 10 分钟）。
- 连续无交互 ≥ 10 分钟自动进入 `sleep`；任意点击/拖拽/计时开始唤醒。
- 精力 < 30 时，坐下/睡觉概率翻倍；心情 < 30 时，走路概率减半并使用 `droop` 待机。
- 自主走动不得越过工作区边界，不得进入任务栏/Dock 区域。
- 用户正在拖拽、菜单打开、设置窗口聚焦时暂停自主行为。

**验收**：静置 5 分钟能观察到至少 3 种行为；不会走出屏幕；不会在计时中乱走。

#### FR-PET-05 点击与互动（MUST）

- **单击**：播放 `react`；心情 +1（同一 5 分钟内只加一次）；若在睡觉则唤醒。
- **双击**：显示/隐藏气泡窗（若计时进行中，显示倒计时；否则显示快捷操作）。
- **右键**：在光标位置弹出原生菜单（见 FR-SYS-02）。
- 点击透明区域不应触发反应（命中区域为角色包围盒）。
- 点击穿透模式下所有点击穿透到下层窗口。

**验收**：快速连点不会叠加多个 `react`；双击不会同时触发两次单击反应；穿透模式下点击不拦截。

#### FR-PET-06 点击穿透（MUST）

- 入口：托盘菜单、右键菜单、全局快捷键 `Ctrl+Alt+X` / `Cmd+Option+X`。
- 开启后：
  - 宠物窗口忽略鼠标事件；
  - 小人透明度 60%，并显示一个锁形小标识（仅视觉，不拦截点击）；
  - 气泡窗隐藏；
  - 托盘图标显示“穿透中”状态。
- 关闭后恢复不透明度与交互；状态持久化，重启后保持。
- 首次开启时用气泡提示“摸鱼模式：我不会挡住你。按当前平台的穿透快捷键恢复。”
- 安全阀：若托盘不可用且穿透快捷键注册失败，禁止开启穿透，托盘/右键菜单对应项置灰并说明原因。

**验收**：开启后能点击小人下方的窗口；快捷键可恢复；重启后状态一致。

#### FR-PET-07 多显示器与 DPI（MUST）

- 支持多显示器；小人只存在于一个显示器。
- 运行时若显示器分辨率/缩放变化，窗口位置夹取到工作区，角色按新的 DPI 重新栅格化。
- 显示器断开：迁移到主屏右下角。
- 记住“显示器标识 + 归一化坐标”；显示器重新接回时优先恢复。

**验收**：双屏拖拽正常；修改系统缩放后角色不模糊、不越界。

#### FR-PET-08 全屏与遮挡（MUST）

- 提供“显示/隐藏”快捷键 `Ctrl+Alt+H` / `Cmd+Option+H` 与托盘开关。
- 不自动检测全屏应用（跨平台成本高）；在设置中提供“演示模式：隐藏小人”说明。
- 点击穿透与隐藏状态在重启后保持。

### 4.2 番茄钟（FR-POM）

#### FR-POM-01 阶段与默认值（MUST）

| 阶段 | 默认时长 | 说明 |
|---|---|---|
| 专注 | 25 分钟 | 可 1–120 分钟 |
| 短休 | 5 分钟 | 可 1–60 分钟 |
| 长休 | 15 分钟 | 每 4 轮专注后进入，可 1–120 分钟 |

- 轮次默认 4，可 2–8。
- 默认**不自动**进入下一阶段；用户点击“开始休息/继续专注”或开启自动开始。
- 长休结束后轮次计数归零。

#### FR-POM-02 控制（MUST）

支持：开始、暂停、继续、跳过、重置、停止。

| 操作 | 行为 |
|---|---|
| 开始 | 从当前阶段完整时长开始 |
| 暂停 | 冻结剩余时间，宠物回到 `idle`（或 `sit`） |
| 继续 | 从剩余时间继续，宠物回到 `focus` / `break` |
| 跳过 | 当前阶段标记 `skipped`，进入下一阶段；专注跳过不计完成轮次 |
| 重置 | 丢弃当前未完成的计时（不写入统计），当前阶段回到完整时长并暂停；已完成的今日统计保留 |
| 停止 | 结束整个番茄钟，回到 idle；当前阶段标记 `interrupted` |

#### FR-POM-03 完成与通知（MUST）

- 阶段结束：
  - 写入 `focus_sessions`（专注阶段）；
  - 发送系统通知（本地化标题/正文）；
  - 宠物 `celebrate` 3 秒；
  - 气泡显示下一阶段与“开始/稍后”按钮；
  - 若通知权限被拒，气泡作为兜底，并在设置页提示。
- 完成专注：心情 +3、精力 -5；完成休息：精力 +8、心情 +1。
- 统计口径：只有 `completed=1` 的专注阶段计入“完成轮次”；`actual_sec` 计入专注分钟数。

#### FR-POM-04 自定义（MUST）

- 设置页可修改三个时长与轮次；非法值即时夹取并在输入框下方提示。
- 修改只影响下一次开始的阶段；进行中的计时不受影响。
- 提供“恢复默认”按钮，二次确认。

#### FR-POM-05 气泡倒计时（MUST）

- 气泡显示：阶段名、`MM:SS`、进度环、暂停/继续、跳过、关闭。
- 计时中每 250ms 更新一次显示；实际剩余时间以 Rust 侧为准。
- 气泡跟随宠物窗移动，位置在宠物上方 8px；空间不足时显示在下方。
- 点击穿透时气泡隐藏；关闭气泡不停止计时。
- 双击宠物可重新打开气泡。

#### FR-POM-06 休眠、重启与时间跳变（MUST）

- 系统休眠/唤醒：以墙钟时间重算剩余；若已到期，只结算一次并通知。
- 应用退出/崩溃：每 5 秒持久化计时快照（阶段、开始时间、剩余秒数、轮次）。
  - 重启时若快照存在且未到期：恢复为**暂停**状态，气泡提示“上次专注未完成，继续吗？”；
  - 若已到期：标记完成，写入记录，提示“上次专注已完成”；
  - 用户可选择“放弃”。
- 检测到系统时间大幅回拨/前跳（> 60 秒）时，以快照剩余时间与单调时钟为准，避免负数或重复结算。

### 4.3 计时器（FR-TMR）

#### FR-TMR-01 正计时（MUST）

- 从 00:00 开始累加，最大 99:59:59。
- 支持开始、暂停、继续、重置。
- 不产生完成通知；停止时可选“保存为专注记录”（默认不保存，避免污染统计）。

#### FR-TMR-02 倒计时（MUST）

- 支持 1 秒–24 小时；预设 5/10/15/30/60 分钟；支持自定义。
- 结束：系统通知 + 宠物 `celebrate` + 气泡“时间到”。
- 可暂停/继续/重置；结束记录 `timer` 类型的 session（不计入番茄轮次）。

#### FR-TMR-03 互斥规则（MUST）

- 同一时间只允许一个活动计时（番茄钟 / 正计时 / 倒计时）。
- 已有活动计时时启动另一个，弹出确认：“先结束当前计时？”；确认后停止旧的并启动新的。
- 暂停中的计时仍视为活动计时，直到停止/重置。

#### FR-TMR-04 气泡与托盘（MUST）

- 气泡显示当前计时类型与时间；正计时显示 `HH:MM:SS`。
- 托盘菜单显示当前计时摘要，并提供暂停/继续/停止。
- 计时结束不自动开始另一个。

### 4.4 健康提醒（FR-RMD，P1）

#### FR-RMD-01 提醒类型（SHOULD）

| 类型 | 默认间隔 | 默认开关 | 文案示例 |
|---|---|---|---|
| 喝水 | 45 分钟 | 开 | 该喝水啦，顺手接一杯吧。 |
| 久坐 | 60 分钟 | 开 | 坐太久啦，起来走两步。 |
| 护眼 | 20 分钟 | 开 | 看看 6 米外，让眼睛休息 20 秒。 |

- 间隔范围 15–180 分钟，可单独开关。
- 护眼提醒采用 20-20-20 规则文案，但不强制锁屏。

#### FR-RMD-02 活跃时段与安静时段（SHOULD）

- 默认活跃 08:00–22:00；安静时段为活跃时段的补集（22:00–08:00），不单独配置。
- 安静时段内不弹通知、不播放提醒动画；到期提醒顺延到下一个活跃时段开始后 5 分钟。
- 活跃时段可配置，至少保留 1 小时；允许跨天（如 20:00–06:00）。
- 专注进行中：默认**只发系统通知，不播放宠物动画**；设置项“专注时暂停全部提醒”默认关闭。

#### FR-RMD-03 提醒交互（SHOULD）

- 触发：系统通知 + 气泡卡片 + 宠物 `remind` 动画（专注时除外）。
- 气泡按钮：`知道了`（重置间隔）、`5 分钟后`、`10 分钟后`。
- 系统通知点击后打开对应气泡/设置页（平台能力允许时）。
- 同一类型提醒在 5 分钟内不重复触发。
- 通知权限被拒：仅气泡，不报错。

#### FR-RMD-04 状态持久化（SHOULD）

- 持久化每类提醒的 `enabled`、`interval_sec`、`next_due_at`、`last_fired_at`。
- 启动时若 `next_due_at` 已过期且处于活跃时段，延迟 30 秒后触发一次；否则按新间隔重排。
- 修改间隔后立即重排下一次。

### 4.5 待办（FR-TODO，P1）

#### FR-TODO-01 数据与操作（SHOULD）

- 字段：标题（必填，1–120 字符）、备注（可选，≤500 字符）、截止时间（可选）、提醒时间（可选）、完成状态。
- 操作：新增、编辑、勾选完成、取消完成、删除（二次确认）、排序（按创建顺序，可拖拽）。
- 列表分组：未完成（按截止时间升序，无截止在后）、已完成（默认折叠）。
- 筛选：全部 / 今天 / 已完成；搜索标题（可选，P1 内做）。
- 空状态文案与插画占位。

#### FR-TODO-02 提醒（SHOULD）

- 设置提醒时间后，到点发送系统通知 + 气泡卡片 + 宠物 `remind`。
- 气泡按钮：`完成`、`10 分钟后`、`关闭`。
- 逾期未完成：列表中红色标记“已逾期”，不重复轰炸通知。
- 待办与番茄钟**相互独立**：开始番茄钟不要求选择待办，完成待办也不影响专注统计。

#### FR-TODO-03 快捷入口（SHOULD）

- 托盘菜单显示“今日待办（N）”，展开前 3 条，可勾选完成。
- 右键小人菜单提供“添加待办”，打开设置窗待办页并聚焦输入框。
- 气泡在无计时时可显示今日待办摘要（最多 3 条）。

### 4.6 专注统计（FR-STAT，P1）

#### FR-STAT-01 数据口径（SHOULD）

统计基于 `focus_sessions`：

- **专注分钟数**：`completed=1` 的专注阶段 `actual_sec` 之和 / 60，四舍五入到整数。
- **完成轮次**：`completed=1` 且 `kind=pomodoro_focus` 的记录数。
- **完成率**：完成轮次 / 开始的专注阶段数（含中断/跳过），无开始则为 `—`。
- **休息分钟数**：完成的短休/长休 `actual_sec` 之和。
- 计时器产生的记录单独统计，不计入番茄轮次。

#### FR-STAT-02 视图（SHOULD）

- 时间范围：今日 / 近 7 天 / 近 30 天。
- 今日：4 个数字卡片（专注分钟、完成轮次、完成率、休息分钟）。
- 7/30 天：数字卡片 + 每日专注分钟柱状图；柱状图可悬停显示数值。
- 无数据：空状态“还没有专注记录，开始第一轮吧”，附“开始专注”按钮。
- 数据全部本地；不提供导出（P2 候选）。

#### FR-STAT-03 性能（SHOULD）

- 30 天查询在 100ms 内返回（本地 SQLite 聚合）。
- 跨天边界按本地 00:00 切分；修改系统时区后按新时区重新聚合。

### 4.7 极简养成（FR-GROW，P1）

#### FR-GROW-01 数值（SHOULD）

- 心情 `mood` 0–100，初始 70；精力 `energy` 0–100，初始 80。
- 变化规则：

| 事件 | 心情 | 精力 |
|---|---|---|
| 完成一轮专注 | +3 | -5 |
| 完成一次休息 | +1 | +8（长休 +15） |
| 单击互动（5 分钟冷却） | +1 | 0 |
| 连续 1 小时无交互 | -1 | 0 |
| 应用关闭期间 | 0 | 每小时 +4，最多 +24 |
| 连续使用 1 小时 | 0 | -2 |

- 下限 20，上限 100；**不会死亡、不会生病、不会锁定功能**。
- 低心情（<30）：`idle` 使用 `droop` 变体；低精力（<30）：更多坐下/睡觉。
- 数值变化不弹通知，不制造负罪感；设置页可查看与重置。

#### FR-GROW-02 持久化（SHOULD）

- 保存 `mood`、`energy`、`last_interaction_at`、`last_decay_at`。
- 启动时按离线时长结算精力恢复；不补算心情衰减超过 24 小时。
- 重置养成数据需二次确认。

## 5. 业务流程

### 5.1 首次启动

```
启动
  │ 读取设置：first_run?
  ├─ 是 → 引导窗（语言/自启/通知/快捷键）
  │        → 写入设置 → 创建宠物窗 → 问候动画 + 气泡
  └─ 否 → 读取位置/尺寸/穿透/计时快照
           → 创建宠物窗 → 恢复状态
                ├─ 计时快照未到期 → 暂停恢复 + 提示
                ├─ 计时快照已到期 → 结算 + 通知
                └─ 无快照 → idle
```

### 5.2 专注闭环

```
选择专注（右键/托盘/快捷键/气泡）
  → 校验无其他活动计时（有则确认停止）
  → Rust 创建 session（planned_sec, started_at）
  → 宠物 focus + 气泡倒计时 + 托盘状态更新
  → 暂停/继续/跳过/停止（任意时刻）
  → 到时：
      写入 focus_sessions（completed）
      → 通知 + celebrate
      → 轮次 +1
      → 轮次 % N == 0 ? 长休 : 短休
      → 自动开始开？→ 直接进入休息；否 → 等待用户
  → 休息结束：
      写入休息记录 → 通知 → 宠物 idle → 等待下一轮
```

### 5.3 计时器闭环

```
选择正计时/倒计时
  → 互斥检查
  → 倒计时：到时通知 + celebrate + 记录 timer session
  → 正计时：用户停止 → 可选保存记录（默认否）
```

### 5.4 健康提醒闭环

```
调度器按 next_due_at 唤醒
  → 是否活跃时段？否 → 顺延
  → 是否专注中？是 → 仅系统通知（可配置暂停）
  → 系统通知 + 气泡 + remind 动画
  → 用户：知道了（重排）/ 5 分钟 / 10 分钟
  → 更新 last_fired_at / next_due_at
```

### 5.5 待办闭环

```
设置窗/托盘/右键 → 新增待办
  → 校验标题 → 入库
  → 若设置提醒 → 计算 remind_at → 调度
  → 到点：通知 + 气泡（完成/10 分钟/关闭）
  → 完成：completed=1 + completed_at → 列表折叠
```

### 5.6 点击穿透

```
入口：托盘 / 右键 / 快捷键
  → 切换 ignore_cursor_events
  → 开启：透明度 60% + 锁标识 + 隐藏气泡 + 托盘标记
  → 关闭：恢复透明度 + 清除标识 + 恢复交互
  → 写入设置（跨重启）
```

### 5.7 退出与恢复

```
退出（托盘/右键）
  → 确认弹窗（有活动计时时强调会停止）
  → 停止计时 → 写入快照/中断记录
  → 保存窗口位置、设置、养成数值
  → 注销快捷键/托盘 → 退出进程
```

### 5.8 统计聚合

```
focus_sessions
  → 按本地日期分组（started_at）
  → completed=1 的专注记录求和 actual_sec
  → 计算轮次、完成率、休息分钟
  → 今日 / 7 天 / 30 天返回
```

## 7. 非功能需求

### 7.1 性能

- 冷启动到小人可见 ≤ 2 秒（中端 SSD 机器）。
- 空闲 CPU 平均 < 1%；动画播放时 < 5%。
- 内存占用 < 200MB（含 WebView）。
- 窗口移动/动画 ≥ 30fps，目标 60fps。
- 设置页切换 Tab ≤ 100ms；统计 30 天查询 ≤ 100ms。

### 7.2 可靠性

- 崩溃后重启不丢待办、设置、养成数值；计时最多丢 5 秒。
- 数据库迁移失败不破坏原文件。
- 单实例；重复启动不产生第二个托盘图标。
- 所有系统集成失败（通知/快捷键/自启）都有降级与提示，不导致应用不可用。

### 7.3 兼容性

- Windows 10 1909+ / Windows 11（WebView2 运行时）。
- macOS 12+（Apple Silicon 与 Intel）。
- Ubuntu 22.04+ / 其他主流发行版（X11 主验证；Wayland 降级）。
- 高 DPI 100%–200%；多显示器混合缩放。

### 7.4 可访问性

- 设置窗完整键盘导航、可见焦点环、语义化标签。
- 文本对比度 ≥ WCAG AA；不仅靠颜色传达状态。
- 支持“减少动态效果”：关闭自主走动与大幅动画。
- 托盘/快捷键提供不依赖鼠标的操作路径。
- 角色为装饰性内容，不强制屏幕阅读器朗读；关键状态通过托盘 tooltip 与设置页文本表达。

### 7.5 安全与隐私

- 无网络请求；CSP 禁止远程资源。
- Tauri capabilities 最小权限；不开放文件系统通配。
- 日志脱敏；待办正文不写日志。
- 卸载/清除数据提供明确入口。

### 7.6 国际化

- 中英双语，全部用户可见文案（含托盘、通知、气泡、错误提示）。
- 文案 key 统一管理；缺失回退英文。
- 日期/时间/数字本地化。

## 8. 验收标准

### 8.1 P0

**宠物**

- [ ] 三端启动只看到透明背景上的小人，无边框/白底。
- [ ] 默认右下角，距边 24px；拖拽后可吸附边缘。
- [ ] 重启后位置、尺寸、穿透状态恢复。
- [ ] 静置 5 分钟可观察到待机、走动、坐下/睡觉等行为。
- [ ] 单击/双击/右键行为正确；穿透模式下点击不拦截。
- [ ] 番茄钟开始/暂停/继续/结束，宠物状态在 300ms 内同步。
- [ ] 双屏、拔屏、DPI 变化后小人不越界、不模糊。

**番茄钟 / 计时器**

- [ ] 25/5/15、4 轮逻辑正确；跳过/重置/停止语义正确。
- [ ] 完成时系统通知 + 宠物庆祝 + 气泡下一阶段。
- [ ] 休眠/重启后计时恢复或结算正确。
- [ ] 同时只能有一个活动计时；互斥确认生效。
- [ ] 正计时/倒计时/预设/自定义正确。

**系统与设置**

- [ ] 托盘菜单动态状态正确；右键菜单可用。
- [ ] 三项快捷键可注册、可修改、冲突有提示。
- [ ] 首次引导 3 步完成；语言/自启/通知权限写入。
- [ ] 中英切换立即生效，托盘/通知同步。
- [ ] 设置窗 P0 5 个 Tab（通用/计时/外观/快捷键/关于）可访问；P1 3 个 Tab 上线后全量 8 个。
- [ ] 关闭设置不退出；退出有确认；单实例生效。

**数据**

- [ ] 设置、位置、计时快照、专注记录持久化。
- [ ] 清除数据后回到首次引导。
- [ ] 无网络请求；日志不含待办正文。

### 8.2 P1

**健康提醒**

- [ ] 三类提醒按间隔触发；安静时段顺延。
- [ ] 专注中默认仅通知；可配置暂停。
- [ ] 知道了/5 分钟/10 分钟行为正确；重启后状态保留。

**待办**

- [ ] 增删改查、完成/取消、筛选、排序正确。
- [ ] 提醒到点通知 + 气泡；逾期样式正确。
- [ ] 与番茄钟互不影响。

**统计**

- [ ] 今日/7 天/30 天数字与柱状图正确。
- [ ] 完成率分母包含中断/跳过；空状态正确。
- [ ] 跨天/时区变化聚合正确。

**养成**

- [ ] 专注/休息/互动数值变化正确；下限 20。
- [ ] 低心情/低精力影响动画，不影响功能。
- [ ] 重启后数值与离线恢复正确；可重置。
