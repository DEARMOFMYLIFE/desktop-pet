## 2. CSS 类与设计 Token

- 页面不复用原生 `<select>`；统一 `Select`。
- 按钮统一 `Button` / `IconButton`，底层复用 `.btn` 系列。
- 卡片统一 `.card` / `SettingsCard`。
- 输入统一 `Input` / `Textarea` / `NumberInput`。
- 提示统一 `Notice`、`.notice`。
- 状态徽标复用 `.badge`。
- 错误提示复用 `.notice-error`。
- 颜色、圆角、阴影、间距均来自 `styles/tokens.css` 与 Tailwind 映射。

## 3. 数据请求封装

| 请求 | 封装位置 |
|---|---|
| 应用/设置/宠物/计时/待办/提醒/统计 IPC | `lib/ipc/api.ts` |
| 浏览器 mock | `lib/ipc/mock/` |
| 角色 manifest / 图片 URL | `lib/character/api.ts` |
| 页面业务动作 | `hooks/useXxx.ts` |
| 页面组件 | 不直接 `fetch` / `invoke`，只消费 hooks |

已检查：

- `frontend/src/**/*.tsx` 无 `from '...lib/ipc'` 直连
- 前端所有 `fetch` 只在 `lib/character/api.ts`
- 后端 IPC 命令按域在 `backend/src/commands/`
