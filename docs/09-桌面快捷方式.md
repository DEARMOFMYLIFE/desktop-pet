# 09 · 桌面快捷方式与启动

> 日期：2026-11-13

---

## 1. 启动入口结构

```text
desktop/
├── yuzu                     # Linux x86_64 静态 ELF 启动器
├── launcher/
│   ├── main.go / env.go / ui.go / fs.go
│   ├── build.sh             # 构建 Linux ELF
│   └── prepare.sh           # 准备本地 Tauri 程序与运行库
├── open-app-macos.command   # macOS 入口
├── open-app-windows.cmd     # Windows 入口
├── scripts/                 # 各平台快捷方式安装函数
├── resources/bin/           # 本机 Tauri 程序（不提交）
├── resources/lib/           # 可选本地运行库（不提交）
├── launcher.env             # 本机运行配置（不提交）
└── README.md
```

Linux 使用 ELF 启动器；macOS 和 Windows 使用各自的入口文件。ELF 负责定位程序、
检查图形显示、设置本地运行库路径并显示错误，不把 Tauri/WebKitGTK 打包进单文件。

---

## 2. 直接打开

```bash
./desktop/yuzu
```

查找顺序：

1. `YUZU_NATIVE_BINARY`
2. `desktop/resources/bin/yuzu`
3. `backend/target/release/yuzu`
4. `backend/target/debug/yuzu`

本地 sysroot 环境：

```bash
./desktop/launcher/prepare.sh \
  --binary /tmp/xz-native-target/release/yuzu \
  --libdir /tmp/xz-merged-lib
```

该命令会复制程序到 `desktop/resources/bin/yuzu`，并生成不提交的
`desktop/launcher.env`。启动器会优先使用 bubblewrap + 本地库目录；没有 bwrap
时回退到 `LD_LIBRARY_PATH`。

重新构建 ELF：

```bash
./desktop/launcher/build.sh          # amd64
./desktop/launcher/build.sh arm64    # arm64
```

## 3. 安装桌面快捷方式

```bash
./install-desktop.sh              # 安装
./install-desktop.sh --uninstall  # 卸载快捷方式，保留应用与数据
./install-desktop.sh --help
```

- **Linux**：写入 `~/.local/share/applications/com.yuzu.app.desktop` 和
  `~/Desktop/Yuzu.desktop`，`Exec` 指向 `desktop/yuzu`。
- **macOS**：优先链接 Tauri `.app`；没有 `.app` 时创建 `Yuzu.command`。
- **Windows Git Bash**：创建 `Yuzu.lnk`；没有 PowerShell 时回退为 `Yuzu.cmd`。

旧的 `scripts/install-desktop-shortcut.sh` 保留为兼容入口，会转发到根目录脚本。

## 4. 浏览器预览

```bash
./start.sh          # Vite 开发服务
./start.sh --prod   # 构建后启动生产预览
./start.sh --build  # 仅构建前端
./start.sh --app    # 直接打开原生应用
./start.sh --open   # 启动后自动打开浏览器
```

浏览器预览使用 mock IPC，与原生 SQLite 数据隔离。

## 5. 验证

```bash
file desktop/yuzu
ldd desktop/yuzu

./desktop/yuzu --help
./install-desktop.sh
desktop-file-validate ~/.local/share/applications/com.yuzu.app.desktop
gtk-launch com.yuzu.app.desktop
```

已在本机验证：

- Linux 启动器为静态 ELF
- 从项目外目录启动可正常运行
- 桌面项校验通过，`gtk-launch` 可聚焦/启动应用
- 安装与卸载快捷方式均不影响应用数据
