# 09 · 桌面快捷方式与启动

> 日期：2026-11-11

---

## 1. 正式安装包

发布包内置：

```text
packaging/com.yuzu.app.desktop
```

安装到系统应用目录：

```bash
sudo install -Dm644 packaging/com.yuzu.app.desktop \
  /usr/share/applications/com.yuzu.app.desktop
```

前提：安装包把可执行文件 `yuzu` 放入 `PATH`，并把应用图标安装为 `yuzu`。正式 Tauri 安装包应由打包流程完成这两步。

桌面项：

- 名称：小柚
- 图标：应用图标
- 分类：Utility
- 启动：`yuzu`

---

## 2. 开发环境快捷方式

安装到应用菜单和桌面：

```bash
./scripts/install-desktop-shortcut.sh --dev
```

默认执行：

```text
scripts/launch-desktop.sh
```

启动顺序：

1. `YUZU_NATIVE_BINARY` + `YUZU_NATIVE_LIBDIR`（本地 sysroot 环境）
2. `backend/target/release/yuzu`
3. `backend/target/debug/yuzu`
4. `scripts/launch-dev.sh` → `npm run tauri -- dev`

本地 sysroot 的当前机器可以使用：

```bash
./scripts/install-desktop-shortcut.sh --dev \
  --native-binary <release-binary> \
  --native-libdir <native-libdir>
```

生成：

- `~/.local/share/applications/com.yuzu.app.desktop`
- `~/Desktop/Yuzu.desktop`

> `YUZU_NATIVE_*` 路径只写入本机生成的 `.desktop` 文件，不写入项目源码或文档中的固定路径。

---

## 3. 验证

```bash
desktop-file-validate ~/.local/share/applications/com.yuzu.app.desktop
gtk-launch com.yuzu.app.desktop
```

本机已验证：

- desktop entry 校验通过
- `gtk-launch` 可启动应用
- 桌面快捷方式文件已创建
