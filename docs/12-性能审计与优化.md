## 1. 重渲染审计

### 已优化

| 位置 | 问题 | 处理 |
|---|---|---|
| Linux 宠物渲染 | 透明 WebView 逐帧重绘产生残影，且 rAF 受后台节流影响 | 改用原生 GTK/Cairo 窗口与 GTK 定时器，逐帧清空 Cairo surface；不触发 React 渲染 |
| Windows/macOS 宠物渲染 | Canvas 动画期间触发 React 渲染 | `useSpriteAnimation` 直接绘制 Canvas，并用 rAF 更新帧 |
| PetStage | 父层 hint/settings 变化会重复渲染 | `memo(PetStage)` + `useCallback` 稳定事件回调 |
| 设置侧边栏 | 设置保存时侧边栏整体重渲染 | `memo(SettingsSidebar)`，并显式接收 `language` 保证语言切换正确 |
| 设置 Header | 设置更新时重复渲染 | `memo(SettingsHeader)` |
| 待办工具栏 | 表单输入时跟着重渲染 | `memo(TodoToolbar)` + `language` 显式依赖 |
| 待办列表 | 表单输入/搜索输入时重新渲染所有行 | `memo(TodoList)` + 稳定 `useCallback` |
| 搜索过滤 | 输入时立即过滤大数组 | `useDeferredValue` 延迟过滤 |

### 保留的必要渲染

- 气泡计时每秒更新：必须更新秒数。
- 设置保存：需要反映保存后的设置。
- 待办表单输入：受控输入必须重渲染。

## 2. 大列表与虚拟滚动

| 列表 | 规模 | 结论 |
|---|---|---|
| 待办列表 | 用户手工录入，通常几十条 | 暂不引入虚拟滚动 |
| 统计柱状图 | 最多 30 天 | 不需要 |
| 提醒列表 | 固定 3 类 | 不需要 |
| 设置导航 | 固定 8 项 | 不需要 |

当前优化：

- 待办筛选 `useMemo`
- 搜索 `useDeferredValue`
- `.todo-row { content-visibility: auto; contain-intrinsic-size: auto 48px; }`
- 如果后续待办达到数百条，再引入 `react-window` 类虚拟列表。

## 3. 图片与资源

| 资源 | 处理 |
|---|---|
| 角色预览 `preview.png` | `loading="lazy"` + `decoding="async"` |
| 角色动作图 | 当前状态才设置 `background-image`，切换时加载；CSS 缓存命中 |
| 品牌 mascot.png | `decoding="async"` |
| Lucide 图标 | 按需 import，Vite tree-shaking |
| 角色 manifest | 按皮肤加载一次；卸载时 disposed guard |

Linux 角色渲染使用 `backend/src/native_pet/` 的原生 GTK/Cairo 窗口：按 manifest 从 Tauri AssetResolver 读取 WebP，解码为 Cairo surface，窗口整面透明清空后绘制单帧。Windows/macOS 继续使用前端 Canvas 渲染。

## 4. 定时器 / 监听器 / 连接

| 位置 | 清理 |
|---|---|
| `usePetWindow` 点击复位、hint 定时器 | ref 保存，卸载清理 |
| `PetStage` 单击延迟定时器 | 卸载清理 |
| `useSettingsWindow` Toast 定时器 | 清理 |
| `useBubbleWindow` timer/settings/reminder 订阅 | 异步返回竞态处理，卸载注销 |
| `useBubbleWindow` focus/visibilitychange | 卸载移除 |
| `usePetWindow` settings/pet 订阅 | 异步返回竞态处理，卸载注销 |
| `useSettingsWindow` settings 订阅 | 异步返回竞态处理，卸载注销 |
| `useSpriteAnimation` requestAnimationFrame | 卸载/状态切换取消；非循环动画停在末帧，状态机在约 1s 内回退 |
| 原生角色帧定时器 | 16ms 调度，仅在帧变化时 queue draw；非循环动作由 Rust ticker 结束 |
| `useSpriteAnimation` fetch | disposed guard |
| mock 宠物复位定时器 | 重复点击先清旧定时器 |

项目没有 WebSocket、长轮询或前端长连接；Rust 宠物状态 ticker 已从 1Hz 调整为 200ms，让 `react` 等单次动作的末帧停顿缩短到约 0.3–0.6s。
