## 0. 一句话定义

**小柚（Yuzu）** 是一个常驻屏幕边缘的 2D 卡通小人：它会待机、走动、睡觉、对你的点击做出反应，也会在你开始番茄钟时进入工作状态；同时提供番茄钟、计时器、健康提醒、待办和专注统计等轻量效率能力。

它不是 AI 对话产品，不是全桌面宠物，也不是重型任务管理工具。

---

## 1. 任务分类

**判定：Architectural（新项目 / 新子系统）**

理由：

1. 工作区不存在任何桌面端应用代码，无法在既有工程上做增量修改。
2. 涉及新的运行时（Rust + Tauri）、新的窗口形态（透明置顶 / 点击穿透）、新的动画资产管线、三端打包，属于从零搭建的独立产品。
3. 需要完整走完：上下文探索 → 结构化澄清 → 方案对比 → 范围分层 → 书面设计 → 用户审批 → 下游文档。

因此不适用“小改动”路径，四份文档全部产出。

## 4. 方案对比

### 4.1 桌面运行时

| 方案 | 优势 | 代价 | 结论 |
|---|---|---|---|
| **A. Tauri 2 + Rust + React/TS** | Rust 是真正的应用主进程；安装包 ~8–15MB；透明置顶、点击穿透、托盘、快捷键、通知均有官方能力；前端迭代快 | 三端 WebView 有差异；Linux 依赖 WebKitGTK；Wayland 透明窗口受限 | **选定** |
| B. Electron + Rust sidecar | 前端生态最成熟，透明窗口稳定 | 双运行时；安装包 100MB+；Rust 只能做子进程，IPC 复杂；不符合“Rust 后端”的干净边界 | 否决 |
| C. 纯 Rust 原生（winit + wgpu + egui/slint） | 单二进制、性能最好、无 WebView | 设置页、气泡、i18n、表单全部手写；动画与 UI 迭代慢；开发成本明显高于 A | 否决（保留为远期轻量版可能） |

**选定 A 的理由**：Rust 主进程满足硬约束；WebView 只负责“画小人 + 设置界面”，正好是 React 的强项；2D 序列帧用 Canvas 2D 即可，不需要 Live2D/Spine 重管线。

### 4.2 角色渲染

| 方案 | 优势 | 代价 | 结论 |
|---|---|---|---|
| **Canvas 2D + 序列帧 sprite sheet** | 与 CC0 素材天然匹配；状态机简单；性能可控；易于替换皮肤 | 需要规范帧尺寸、锚点、命名 | **选定** |
| Live2D | 表现力强、可跟随鼠标 | 需要 Cubism SDK 与授权；素材管线重；开源素材少 | 否决（P2 可选） |
| Lottie / Rive | 矢量、体积小、可交互 | 依赖设计稿；CC0 卡通小人素材少 | 否决 |
| 3D（glTF + WebGL） | 立体表现 | 体积、性能、素材、跨端一致性成本最高 | 否决 |

### 4.3 窗口形态

| 方案 | 说明 | 结论 |
|---|---|---|
| 全屏透明覆盖层 | 小人可在任意位置走动 | 否决：点击穿透区域管理复杂、性能开销大、易误触 |
| **小型透明置顶窗口** | 窗口跟随小人移动，默认贴边；可拖拽；点击穿透是窗口级开关 | **选定** |
| 固定角落 | 不移动，只做待机 | 否决：缺少“自主行为”的空间感 |

### 4.4 数据存储

| 方案 | 说明 | 结论 |
|---|---|---|
| **SQLite（Rust `rusqlite`，bundled）** | 结构化存专注记录、待办、提醒状态、养成数值；支持迁移与聚合查询 | **选定** |
| JSON 文件 | 简单，但统计聚合、并发写入、迁移都更脆弱 | 否决 |
| IndexedDB / localStorage | 数据在 WebView 内，Rust 调度器读不到；卸载/清缓存易丢 | 否决 |

### 4.5 决策汇总

| 维度 | 决策 |
|---|---|
| 运行时 | Tauri 2.x |
| 后端 | Rust stable（2021 edition 及以上） |
| 前端 | React 18 + TypeScript + Vite |
| 状态管理 | Zustand |
| 动画 | Canvas 2D + sprite sheet 状态机 |
| 存储 | SQLite（`rusqlite` bundled）+ 版本化迁移 |
| 窗口 | 宠物窗（透明置顶）+ 气泡窗（独立）+ 设置窗（普通）+ 首次引导窗 |
| 系统集成 | 托盘、原生右键菜单、全局快捷键、系统通知、开机自启、单实例 |
| 网络 | 无；完全离线 |
| 打包 | Windows NSIS/MSI、macOS dmg、Linux AppImage/deb |

## 5. 产品边界

### 5.1 目标

1. **陪伴感**：小人常驻桌边，有生命感，不打扰。
2. **轻效率**：番茄钟、计时器、健康提醒、待办、统计形成闭环。
3. **低负担**：极简养成，不死亡、不惩罚、不制造焦虑。
4. **三端可用**：同一套代码与交互，Windows/macOS/Linux 行为一致。
5. **离线可信**：无账号、无联网、数据本地。

### 5.2 非目标（第一版明确不做）

- AI 对话 / 语音助手 / 大模型接入；
- 全桌面自由走动、攀爬窗口、全屏覆盖；
- 账号、云同步、多人社交、排行榜；
- Live2D / 3D / 角色编辑器 / 用户上传素材；
- 复杂项目管理（项目、标签、子任务、看板、协作）；
- 自动更新、应用内购、付费体系；
- 音效、BGM、语音包；
- 移动端 / Web 版。

### 5.3 范围分层

| 层级 | 模块 | 内容 |
|---|---|---|
| **P0** | 宠物核心 | 待机、自主行为、拖拽、点击反馈、状态联动、点击穿透、位置记忆、多屏 |
| **P0** | 番茄钟 | 25/5/15 默认、开始/暂停/继续/跳过/重置、自定义时长、通知、气泡倒计时 |
| **P0** | 计时器 | 正计时、倒计时、预设、完成通知 |
| **P0** | 系统集成 | 托盘菜单、小人右键菜单、设置窗口、全局快捷键、开机自启、单实例 |
| **P0** | 基础体验 | 首次引导、中英双语、SQLite 持久化、崩溃恢复、错误兜底 |
| **P1** | 健康提醒 | 喝水、久坐、护眼；安静时段；稍后提醒 |
| **P1** | 待办 | 单层清单、截止时间、提醒、完成状态 |
| **P1** | 专注统计 | 今日 / 7 天 / 30 天的分钟数、轮次、完成率、柱状图 |
| **P1** | 极简养成 | 心情 / 精力、专注与休息联动、低心情动画，不死亡 |

> P0 是“可交付的最小完整产品”，P1 是“让产品有黏性”的增强层。PRD 对 P1 同样给出完整需求与验收标准，开发按里程碑推进。

## 6. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| Linux Wayland 下透明窗口 / 点击穿透不稳定 | Linux 体验降级 | X11 作为主验证环境；Wayland 检测后降级为圆角不透明窗口，并在设置中提示 |
| 三端 WebView 渲染差异（WebView2 / WKWebView / WebKitGTK） | 动画、字体、透明背景不一致 | 固定最小版本；CSS 能力检测；三端冒烟清单；避免依赖前沿 CSS |
| CC0 中性小人素材风格不统一 | 角色观感廉价 | 优先同一作者/同一套系；统一描边、配色、帧尺寸；必要时做后处理；保留占位角色 |
| 常驻置顶遮挡内容 | 用户反感 | 点击穿透一键切换；显示/隐藏快捷键；默认贴边不遮中央；全屏应用场景提供隐藏入口 |
| 全局快捷键冲突 | 功能不可用 | 注册失败检测 + 设置页提示 + 允许改键 |
| 通知权限被拒（macOS/Windows） | 提醒失效 | 首次引导请求权限；被拒时降级为气泡提醒 + 设置页常驻提示 |
| 系统休眠 / 锁屏导致计时漂移 | 番茄钟不准 | 以墙钟时间重算剩余；恢复时一次性结算；记录 `interrupted` |
| 未签名安装包触发 SmartScreen / Gatekeeper | 安装受阻 | 文档说明；P1 再做签名与公证；提供校验和 |
| Rust / WebKitGTK 环境缺失 | M0 无法启动 | 技术文档列出三端依赖与安装命令；M0 第一项做环境自检脚本 |

## 7. 默认参数与未决项

以下默认值已与用户对齐，将写入 PRD 与交互文档：

| 项 | 默认值 |
|---|---|
| 番茄钟 | 25 分钟专注 / 5 分钟短休 / 每 4 轮 15 分钟长休；不自动进入下一阶段 |
| 计时器 | 正计时 + 倒计时；预设 5/10/15/30/60 分钟 |
| 快捷键 | 专注开关 `Ctrl+Alt+P`（mac `Cmd+Option+P`）；穿透开关 `Ctrl+Alt+X`；显示/隐藏 `Ctrl+Alt+H` |
| 健康提醒 | 喝水 45 分钟、久坐 60 分钟、护眼 20 分钟；活跃 08:00–22:00（安静为其补集） |
| 小人尺寸 | S/M/L = 96/144/192 逻辑像素，默认 M |
| 默认位置 | 主屏右下角工作区，距边缘 24px |
| 点击穿透 | 菜单/快捷键切换；开启后半透明 + 锁形标识；气泡隐藏，托盘仍可操作 |
| 统计口径 | 今日 / 近 7 天 / 近 30 天的专注分钟数、完成轮次、完成率 |
| 待办 | 单层清单：标题、备注、截止时间、提醒、完成状态 |
| 养成 | 心情/精力 0–100，随专注与休息变化，最低 20，不死亡、不惩罚 |

**未决项（不阻塞文档，开发前确认）**：

1. 最终角色素材包（CC0 来源、作者、许可证）——M0 选型，M1 接入。
2. 应用图标与托盘图标——M0 先用占位，M5 前定稿。
3. macOS 是否购买开发者签名 / 公证——P1 决策。
4. 是否提供数据导出（CSV/JSON）——P2 候选。
5. 自动更新——P2 候选。
