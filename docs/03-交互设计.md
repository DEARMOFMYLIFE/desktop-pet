> 版本：v1.0 · 日期：2026-11-09

> 状态：待评审

---

## 1. 设计原则

| 原则 | 落地 |
|---|---|
| **小人优先** | 屏幕上的主角是角色，不是 UI；所有常驻界面都要“轻” |
| **不打扰** | 不抢焦点、不挡内容、不弹全屏；点击穿透与隐藏是一等公民 |
| **可预期** | 自主行为有节奏、有边界；计时状态与动画严格同步 |
| **低负担** | 极简养成、无惩罚；提醒可稍后；设置即时生效 |
| **一眼看懂** | 气泡只放当前最重要的一件事；设置页分组清晰 |
| **三端一致** | 交互语义一致，菜单/快捷键遵循平台习惯 |

### 1.1 视觉基调

**World：Soft Morning / 晨光软糖**

- 暖白纸感底色 + 陶土橘强调色，像清晨桌边的一杯热饮。
- 大圆角、软阴影、细描边；不用玻璃拟态、不用霓虹、不用重渐变。
- 角色是彩色插画，UI 退到中性色，避免和角色抢视觉。
- 设置窗跟随系统亮/暗色；宠物窗永远透明。

**Design Read**：这是给长时间坐在电脑前的普通用户做的陪伴型桌面工具，视觉语言偏温暖、柔和、手作感，而不是冷酷的效率仪表盘。

## 2. 信息架构与窗口清单

| 窗口 | 类型 | 常驻 | 尺寸（逻辑 px） | 说明 |
|---|---|---|---|---|
| 宠物窗 `pet` | 透明、无边框、置顶 | 是 | 176×176（M） | 只画角色；不抢焦点 |
| 气泡窗 `bubble` | 透明、无边框、置顶 | 按需 | 280×自适应（最大 320×220） | 计时、提醒、快捷操作 |
| 设置窗 `settings` | 普通窗口 | 否 | 760×560（最小 680×500） | 左侧导航 + 右侧内容 |
| 首次引导 `onboarding` | 普通窗口 | 否 | 520×420 | 3 步 |
| 托盘菜单 | 原生 | 是 | — | 系统托盘 |
| 右键菜单 | 原生 | 按需 | — | 光标位置弹出 |
| 系统通知 | 原生 | 按需 | — | 计时/提醒/待办 |

**窗口层级**（从低到高）：

```
普通应用窗口 < 设置窗 < 宠物窗 < 气泡窗 < 原生菜单/通知
```

- 宠物窗与气泡窗 `alwaysOnTop`，但不抢键盘焦点。
- 设置窗普通层级，可被其他应用遮挡。
- 原生菜单/通知由系统管理。

## 3. 宠物窗

### 3.1 布局

```
┌──────────────────────────┐  透明背景
│                          │
│          ╭────╮          │
│          │ ◕‿◕ │          │  角色 144×144
│          ╰────╯          │  底部中心对齐
│                          │
└──────────────────────────┘
        176×176（M 码）
```

- 角色底部中心距窗口底边 16px；左右居中。
- 透明内边距用于拖动热区与投影留白，不显示底色。
- 窗口不绘制任何边框、标题栏、关闭按钮。
- 点击热区 = 角色包围盒（可用 `manifest.json` 的 hitbox 微调）。

### 3.2 鼠标交互

| 操作 | 行为 | 反馈 |
|---|---|---|
| 悬停 | 光标变 `grab` | 角色轻微抬头/眨眼（可选） |
| 按下并移动 > 4px | 进入拖拽 | `drag` 动画；窗口跟随 |
| 单击（未拖动） | 互动 | `react` 动画 + 心情 +1（5 分钟冷却） |
| 双击 | 打开/关闭气泡 | 气泡 160ms 弹出/收起 |
| 右键 | 原生菜单 | 菜单在光标处弹出 |
| 拖拽松手 | 吸附边缘 | 距边 ≤48px 吸附；否则停留 |
| 点击穿透中 | 穿透到下层 | 无反馈；角色 60% 透明 |

**点击与拖动判定**：按下后移动距离 ≤4px 且时长 <300ms 视为单击；否则视为拖拽。双击间隔 ≤300ms。

### 3.3 状态与动画

| 状态 | 视觉 | 触发 | 退出 |
|---|---|---|---|
| `idle` | 呼吸、眨眼、偶尔环顾 | 默认 | 其他状态 |
| `walk` | 沿边缘走，身体轻微起伏 | 自主行为 | 到达/打断 |
| `sit` | 坐在边缘，腿晃动 | 自主行为 | 打断/计时 |
| `sleep` | 闭眼、Zzz 气泡 | 10 分钟无交互 | 点击/计时 |
| `focus` | 戴耳机/敲键盘/看屏幕 | 番茄钟专注 | 暂停/结束 |
| `break` | 伸懒腰/喝水 | 短休/长休 | 结束 |
| `celebrate` | 举手/跳跃/星星 | 完成阶段 | 3s 后 |
| `drag` | 被拎起、手脚下垂 | 拖拽 | 松手 |
| `react` | 惊讶/开心 | 单击 | 1.5s 后 |
| `remind` | 招手/指向气泡 | 提醒 | 3s 后 |
| `droop` | 蔫蔫的待机 | 心情 <30 | 心情恢复 |

**优先级**：`drag` > `react`/`celebrate`/`remind` > `focus`/`break` > `sleep`/`sit`/`walk` > `idle`。

**状态同步规则**：

- 计时开始/恢复：宠物在 300ms 内进入 `focus` 或 `break`。
- 计时暂停：宠物回到 `idle`（若 10 分钟无交互可 `sit`）。
- 计时完成：`celebrate` 3s → 下一阶段状态（若自动开始）或 `idle`。
- 提醒触发：`remind` 3s → 回到之前状态（不打断计时）。
- 拖拽优先级最高，松手后回到计时/待机状态。

### 3.4 自主行为节奏

- 每 20–60 秒掷一次行为骰子；同一行为不连续出现 3 次。
- 走动距离 40–160px，速度 40–80px/s；走到边界自动反向或停下。
- 计时中、拖拽中、菜单打开、设置窗聚焦、点击穿透中：**暂停自主走动**（穿透时仍可播放 idle 动画）。
- 连续 10 分钟无交互 → `sleep`；点击/拖拽/计时开始唤醒。
- 精力 <30：坐下/睡觉概率 ×2；心情 <30：走路概率 ×0.5，待机用 `droop`。

### 3.5 点击穿透视觉

```
┌──────────────────────────┐
│                          │
│          ╭────╮  🔒      │  角色 60% 透明
│          │ ◕‿◕ │          │  右下角锁形标识 16×16
│          ╰────╯          │
│                          │
└──────────────────────────┘
```

- 锁形标识为纯视觉，不拦截点击。
- 首次开启时气泡提示恢复方式，3 秒后自动消失。
- 穿透状态写入设置，重启保持。
- **安全阀**：若托盘不可用且快捷键注册失败，禁止开启穿透（菜单项置灰并提示“需要至少一个恢复入口”）。

## 4. 气泡窗

### 4.1 通用规格

- 透明窗口，内容为一张 280px 宽的圆角卡片（最大 320px，高度自适应）。
- 圆角 16px；背景 `#FFFDF9` / 暗色 `#211E1B`；细描边 + 软阴影。
- 位置：宠物窗上方 8px，水平居中对齐；上方空间不足时显示在下方。
- 跟随宠物移动；宠物拖拽时气泡暂时隐藏，松手后 200ms 重新出现。
- 打开/关闭：160ms `opacity + translateY(4px) + scale(0.98→1)`。
- 点击气泡外部关闭（不抢焦点时通过 Rust 全局点击监听或失焦事件实现；实现不了则提供关闭按钮 + Esc）。
- `Esc` 关闭气泡。
- 点击穿透开启时气泡隐藏；关闭穿透后若计时仍在，自动恢复。

### 4.2 计时气泡

```
┌──────────────────────────────┐
│  专注中                25:00 │
│  ●──────────────────────○    │
│  [ 暂停 ]  [ 跳过 ]      [×] │
└──────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 阶段标签 | 14px，次级色；`专注中 / 短休 / 长休 / 正计时 / 倒计时` |
| 时间 | 28px，等宽数字，主色；`MM:SS`，≥1h 用 `HH:MM:SS` |
| 进度环/条 | 4px 高圆角条；已完成部分用强调色；倒计时为正计时方向 |
| 主按钮 | 暂停/继续，胶囊按钮，强调色 |
| 次按钮 | 跳过（专注/休息）或重置（计时器） |
| 关闭 | 右上角 `×`，只关气泡不停止计时 |
| 状态 | 暂停时整体降饱和度，显示“已暂停” |

**交互**：

- 暂停 → 按钮变“继续”，时间停止，宠物回 `idle`。
- 继续 → 时间继续，宠物回对应状态。
- 跳过 → 当前阶段标记 skipped，进入下一阶段；不弹确认（高频操作，允许撤销？不提供撤销，统计如实记录）。
- 关闭 → 气泡消失；宠物仍保持状态；双击/托盘可重新打开。

### 4.3 快捷操作气泡（无计时）

```
┌──────────────────────────────┐
│  今天想做点什么？             │
│  [ 开始专注 25 分钟 ]         │
│  [ 计时器 ]   [ 今日待办 2 ]  │
└──────────────────────────────┘
```

- 无计时、双击宠物时显示。
- “开始专注”直接开始默认番茄钟；“计时器”展开预设 5/10/15/30/60；“今日待办”跳转设置窗待办页（P1）。
- 底部一行小字提示：“右键我可以打开更多”。

### 4.4 提醒气泡

```
┌──────────────────────────────┐
│  💧 该喝水啦                  │
│  顺手接一杯吧。               │
│  [ 知道了 ] [ 5 分钟后 ] [×] │
└──────────────────────────────┘
```

- 图标：喝水 💧 / 久坐 🪑 / 护眼 👀 / 待办 ✅（可用内置 SVG，避免 emoji 平台差异）。
- 标题 15px 加粗；正文 13px 次级色。
- `知道了`：重置间隔；`5 分钟后`：snooze；`×`：关闭，视为稍后 10 分钟（避免误触后永不提醒）。
- 多条提醒排队：一次只显示一条，最多排队 3 条；超出丢弃并只发系统通知。
- 专注中：不显示动画，仅系统通知；若设置“专注时暂停”则不触发。

### 4.5 待办摘要气泡（P1）

```
┌──────────────────────────────┐
│  今日待办 · 2 件              │
│  ☐ 给客户回邮件       18:00  │
│  ☐ 买咖啡豆                  │
│  [ 打开待办 ]                │
└──────────────────────────────┘
```

- 无计时、双击宠物、且今日有待办时，优先于快捷操作显示。
- 勾选后即时完成并播放轻微反馈；列表为空则显示快捷操作。

────────────────────────

```

**规则**：

- 第一行是状态摘要，不可点击；空闲时显示“凪 · 空闲”。
- “开始专注”在计时中置灰；“暂停/继续”按状态切换文案；“停止计时”仅在有活动计时时可用。
- “开始计时器”子菜单：预设 + “自定义…”（打开设置窗计时页并聚焦自定义输入）。
- “显示小人”与“点击穿透”为复选态。
- 托盘 tooltip：`凪 · 专注中 12:34` / `凪 · 空闲` / `凪 · 穿透中`。
- macOS 使用模板图标（黑白），Windows/Linux 使用彩色图标。

### 5.2 小人右键菜单

```
开始专注 25 分钟
暂停 / 继续
停止计时
────────────────────────
打开气泡
摸鱼模式（点击穿透）
────────────────────────
添加待办…            （P1）
设置…
隐藏小人
────────────────────────
退出凪
```

- 原生菜单在光标处弹出；菜单打开时宠物暂停自主行为。
- 无计时时隐藏“暂停/继续”“停止计时”。
- 休息阶段显示“开始休息 / 跳过休息”。
- 点击穿透开启时，右键菜单不可用（因为点击已穿透）；只能从托盘/快捷键恢复。

## 6. 设置窗

### 6.1 整体布局

```
┌──────────────────────────────────────────────────────────┐
│  凪 设置                                        —  □  × │
├──────────────┬───────────────────────────────────────────┤
│  🐣 凪      │  通用                                     │
│              │  语言、启动、窗口与角色                    │
│  通用         │                                           │
│  计时         │  ┌─ 语言 ──────────────────────────────┐  │
│  提醒         │  │ 界面语言      [跟随系统        ▾]  │  │
│  待办         │  └─────────────────────────────────────┘  │
│  统计         │                                           │
│  外观         │  ┌─ 启动与窗口 ────────────────────────┐  │
│  快捷键       │  │ 开机自启                  [ ● ]    │  │
│  关于         │  │ 始终置顶                  [ ● ]    │  │
│              │  │ 启动时显示小人            [ ● ]    │  │
│              │  └─────────────────────────────────────┘  │
│              │                                           │
│              │  ┌─ 角色 ──────────────────────────────┐  │
│              │  │ 尺寸   ( S ) ( M ) ( L )            │  │
│              │  │ 不透明度  ──────●──── 100%          │  │
│              │  │ [重置到默认位置]                    │  │
│              │  └─────────────────────────────────────┘  │
└──────────────┴───────────────────────────────────────────┘
```

**规格**：

- P0 阶段左侧导航仅显示 **通用 / 计时 / 外观 / 快捷键 / 关于** 5 项；M4 起增加 **提醒 / 待办 / 统计**，共 8 项。
- 左侧导航宽 200px，背景比内容区略深；选中项左侧 3px 强调色竖条 + 加粗。
- 右侧内容区最大宽度 600px，左右内边距 32px，顶部 28px。
- 页面标题 20px 加粗；副标题 13px 次级色；分组卡片圆角 16px、1px 描边、无重阴影。
- 设置项行高 ≥44px；标签左对齐，控件右对齐；说明文字在标签下方 12px。
- 底部不设“保存”按钮：**即时保存**，变更后 300ms 防抖写入，右上角轻提示“已保存”（2s 消失）。
- 非法输入：输入框红描边 + 下方错误文案；失焦时夹取到合法范围并提示。
- `Esc` 关闭当前弹窗/下拉，不关闭设置窗；`Cmd/Ctrl+W` 关闭设置窗。
- 再次打开恢复上次 Tab（`last_settings_tab`）。

### 6.2 通用

| 分组 | 控件 | 说明 |
|---|---|---|
| 语言 | Select：跟随系统 / 简体中文 / English | 立即生效 |
| 启动与窗口 | Switch：开机自启、始终置顶、启动时显示小人 | 自启失败提示 |
| 角色 | Segmented：S/M/L；Slider：不透明度 60–100% | 角色实时预览（右侧小舞台） |
| 位置 | 当前显示器 + 坐标；按钮“重置到默认位置” | 重置需确认 |
| 恢复默认 | 文字按钮 | 仅本页，二次确认 |

**角色预览**：卡片右侧放一个 96×96 的静态/待机预览框，切换尺寸/透明度时实时更新；点击预览可让小人做一个 `react`。

### 6.3 计时

| 分组 | 控件 | 校验 |
|---|---|---|
| 番茄钟 | 专注 1–120 分钟；短休 1–60；长休 1–120；轮次 2–8 | 数字输入 + 步进器 |
| 自动开始 | Switch：专注结束后自动开始休息；休息结束后自动开始专注 | 默认关 |
| 计时器预设 | 标签列表，可增删；1–8 个；每个 1–1440 分钟 | 重复值自动去重 |
| 默认模式 | Radio：正计时 / 倒计时 | 默认倒计时 |
| 恢复默认 | 文字按钮 | 二次确认 |

**说明文案**：“修改只影响下一次开始，不会打断正在进行的计时。”

### 6.4 提醒（P1）

| 分组 | 控件 | 说明 |
|---|---|---|
| 提醒开关 | 三行：喝水 / 久坐 / 护眼；每行 Switch + 间隔 NumberField（15–180 分钟） | 关闭时行置灰 |
| 活跃时段 | 两个 TimeField：开始 / 结束 | 至少 1 小时；跨天允许 |
| 安静时段 | 自动为活跃时段的补集，只读展示 | 避免两者冲突 |
| 专注时 | Radio：仅系统通知（默认）/ 暂停全部提醒 | 说明“不打断心流” |
| 稍后时长 | Segmented：5 / 10 分钟 | 气泡与通知共用 |
| 通知权限 | 状态徽标 + “请求权限”按钮 | 被拒时显示系统设置指引 |
| 恢复默认 | 文字按钮 | 二次确认 |

### 6.5 待办（P1）

```
┌──────────────────────────────────────────────────────────┐
│  待办                                [+ 添加待办]        │
│  [ 全部 ] [ 今天 ] [ 已完成 ]        搜索 [        ]      │
│                                                          │
│  ☐ 给客户回邮件                              今天 18:00  │
│  ☐ 买咖啡豆                                             │

## 9. 关键流程时序

### 9.1 开始专注

```
用户右键 → 菜单“开始专注 25 分钟”
  → ipc.timer_start({kind:'pomodoro', phase:'focus', minutes:25})
  → Rust: 校验无活动计时 → 创建 session → 启动调度
  → emit 'timer:started' + 'pet:state' (focus)
  → 前端: timerStore 更新 → 气泡显示 → PetStage 切 focus
  → 托盘菜单刷新（Rust 侧）
```

### 9.2 专注完成

```
Rust 调度到期
  → 写入 focus_sessions(completed=1)
  → 更新养成数值
  → emit 'timer:completed'
  → 系统通知
  → 前端: 气泡显示“完成一轮” → PetStage celebrate 3s
  → 计算下一阶段（短休/长休）
  → 若 autoStartNext → 自动开始；否则气泡显示“开始休息”
  → 托盘状态更新
```

### 9.3 点击穿透

```
用户按穿透快捷键（默认 `Ctrl+Alt+X` / `⌘⌥X`）
  → ipc.set_click_through(true)
  → Rust: window.set_ignore_cursor_events(true) → 保存设置
  → emit 'pet:click_through'
  → 前端: 透明度 60% + 锁标识 + 气泡隐藏
  → 托盘复选态更新
  → 首次：气泡提示 3s（若气泡可用）
```

### 9.4 提醒触发

```
Rust 调度器到期
  → 检查活跃时段 / 专注状态 / 通知权限
  → 系统通知
  → emit 'reminder:fired' {kind}
  → 前端: 气泡 ReminderBubble + PetStage remind 3s（专注中跳过动画）
  → 用户“知道了” → ipc.reminder_ack(kind) → 重排 next_due_at
  → 用户“5 分钟后” → ipc.reminder_snooze(kind, 5)
```

### 9.5 拖拽与吸附

```
pointerdown → 记录起点 → 移动 >4px → ipc.pet_drag_start()
  → Rust: 记录窗口偏移
pointermove → ipc.pet_drag_move(cursor) → Rust 设置窗口位置
pointerup → ipc.pet_drag_end()
  → Rust: 判断距边 ≤48px → 吸附动画（120ms）→ 保存归一化位置
  → emit 'pet:position' → 前端更新气泡位置
```

## 10. 动画与动效规范

### 10.1 角色动画

| 项 | 规范 |
|---|---|
| 帧率 | 8–12 fps（手绘感）；拖拽/庆祝可 12–15 fps |
| 帧尺寸 | 200×200 透明 WebP，角色高约 180px，底部中心锚点 |
| 循环 | `idle` 4–6 帧 / 1.2s；`walk` 8 帧 / 0.8s；`sleep` 4 帧 / 2s |
| 切换 | 交叉淡入 80ms；禁止硬切闪烁 |
| 缩放 | 按逻辑尺寸绘制，DPR 由 Canvas 处理；S/M/L 不改变素材 |
| 减少动态 | 只保留 `idle` 呼吸（2 帧 / 2s），禁用走动与跳跃 |

### 10.2 UI 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 气泡出现 | 160ms | `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| 气泡消失 | 120ms | ease-in |
| 菜单/弹窗 | 150ms | ease-out |
| Tab 切换 | 120ms 淡入 | ease-out |
| Toast | 200ms 进入 / 150ms 退出 | ease-out |
| 窗口吸附 | 120ms | ease-out |
| 数字变化 | 200ms | 线性 |

- 不使用弹跳/弹簧（除角色庆祝动画）。
- 尊重 `prefers-reduced-motion` 与设置项。
- 动画不得阻塞输入；窗口移动在 Rust 侧按帧更新，前端不参与。

### 10.3 状态机

```
                    ┌────────────┐
        ┌──────────►│   idle     │◄──────────┐
        │           └─────┬──────┘           │
        │                 │ 自主行为          │ 完成/停止
        │        ┌────────┼────────┐         │
        │        ▼        ▼        ▼         │
        │     walk      sit      sleep       │
        │        │        │        │         │
        │        └────────┴────────┘         │
        │                 │ 点击/计时          │
        │                 ▼                   │
        │           ┌────────────┐            │
        │           │  react     │            │
        │           └────────────┘            │
        │                                     │
        │  计时开始 ┌────────────┐  计时结束   │
        └──────────│ focus/break│─────────────┘
                   └─────┬──────┘
                         │ 完成
                         ▼
                   ┌────────────┐
                   │ celebrate  │──3s──► 下一状态
                   └────────────┘

  任意状态 ──拖拽──► drag ──松手──► 之前状态（计时中回到 focus/break）
  任意状态 ──提醒──► remind ──3s──► 之前状态（不打断计时）
```

**互斥规则**：同一时刻只有一个主状态；`celebrate`/`remind`/`react` 为一次性叠加层，播放完回到主状态；`drag` 可打断一切。

> 文案规范：短句、口语、不用感叹号堆叠；中文不超过 18 字/行，英文不超过 60 字符/行；避免“您”的过度客套，保持“你”的平视感。
> `{shortcut}` 按平台替换为 `Ctrl+Alt+X`（Windows/Linux）或 `⌘⌥X`（macOS）；其他快捷键同理。

## 12. 边界与异常

| 场景 | 处理 |
|---|---|
| 多显示器 / 拔屏 | 迁移主屏右下；位置夹取；气泡跟随 |
| 任务栏在顶部/左侧 | 使用工作区而非全屏尺寸计算，贴边方向自适应 |
| 任务栏自动隐藏 | 仍按工作区计算，避免遮挡触发区 |
| DPI 100%–200% | 逻辑像素布局；Canvas 按 DPR 缩放；切换后重绘 |
| 全屏应用 / 演示 | 不自动隐藏；提供 `Ctrl+Alt+H` 与托盘隐藏；设置页说明 |
| 锁屏 / 休眠 | 计时按墙钟重算；恢复只结算一次；提醒不补发过期的多条 |
| 系统时间跳变 | 以单调时钟 + 快照为准；检测 >60s 跳变后重算 |
| 通知权限被拒 | 气泡兜底；设置页常驻提示；不阻塞计时 |
| 快捷键冲突 | 注册失败 → 保留旧值 → 输入框报错；不阻塞其他快捷键 |
| 托盘不可用（部分 Linux） | 右键菜单 + 快捷键仍可用；穿透入口在无恢复路径时禁用 |
| 数据库损坏 | 保留原文件，创建新库，提示“数据可能丢失，已备份原文件” |
| 迁移失败 | 只读安全模式；提示备份并退出，不覆盖原库 |
| 角色素材缺失 | 使用内置占位角色（几何小人），记录日志，不白屏 |
| 语言包缺 key | 回退英文；开发环境 console 警告 |
| 第二实例 | 唤醒已有实例并打开设置；不创建第二个托盘 |
| 设置窗已打开 | 聚焦已有窗口，不重复创建 |
| 计时互斥 | 启动新计时前确认停止旧的；取消则保持原计时 |
| 气泡超出屏幕 | 自动翻转/夹取；仍超出则贴边显示 |
| 拖拽中失焦/松手丢失 | 监听 `pointercancel`/失焦，结束拖拽并保存位置 |
| 快速连点 | 300ms 节流；`react` 不叠加 |
| 穿透中无法右键 | 托盘/快捷键恢复；首次开启提示 |
| 减少动态效果 | 禁用走动、跳跃、庆祝位移；保留淡入淡出 |

## 13. 可访问性

- **键盘**：设置窗全部可 Tab 到达；`Enter/Space` 激活；`Esc` 关闭弹层；焦点环 2px 强调色，不被裁切。
- **屏幕阅读器**：设置窗使用语义化 `label`/`fieldset`/`aria-describedby`；Toast 用 `role="status"`；确认弹窗用 `role="alertdialog"` 并聚焦确认按钮。
- **对比度**：正文 ≥4.5:1，大字 ≥3:1；状态不仅靠颜色，配合图标/文字。
- **减少动态**：跟随系统 `prefers-reduced-motion`；设置可强制开启；开启后宠物只保留呼吸，UI 只保留淡入淡出。
- **触控/小屏**：设置窗最小 680×500；按钮点击区域 ≥32×32；不依赖 hover 才能完成操作。
- **宠物**：作为装饰性内容不进入 Tab 顺序；所有功能均可从托盘/快捷键/设置完成。
