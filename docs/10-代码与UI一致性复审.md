## 2. 样式复用审计

项目没有 `.data-table` / `.status-badge` / `.action-btn`；对应的现有基础是：

| 需求类 | 项目现有类 |
|---|---|
| 卡片 | `.card` / `SettingsCard` |
| 表格 | 当前无数据表页面；统计使用 `.stats-*` |
| 状态徽标 | `.badge` |
| 操作按钮 | `.btn` / `Button` |

复用情况：

- `SettingsCard` → `.card`
- `SettingRow` → `.row` + `.row-label`
- `Notice` → `.notice`
- `Button` → `.btn` 系列
- `IconButton` → `.icon-btn`
- `Input` / `Textarea` → `.input` / `.textarea`
- `NumberInput` → `.number-control`
- `Select` → `.select-trigger` / `.select-menu`
- `SearchField` → `.search-field`
- `Checkbox` → `.checkbox`
- `ConfirmDialog` / `LoadingPane` / `ErrorPane` / `Toast`

清理：

- 移除未使用的原生 `.select`
- 移除全局 `.card + .card` 的重复 margin，统一由 `.settings-content` 的 `gap: 14px` 控制
- 移除重复的 `.shortcut-error`，统一为 `.notice-error`
- 按钮阴影统一使用 `--shadow-accent` / `--shadow-danger` token

## 3. 一致性检查与修正

### 间距 / 圆角 / 阴影

| 问题 | 修正 |
|---|---|
| 卡片间距由 margin + flex gap 双重控制 | 统一 `.settings-content { display:flex; gap:14px }` |
| 卡片圆角 16px 偏大 | `--radius-lg: 10px` |
| 按钮圆角 12px 偏大 | `--radius-md: 8px` |
| 输入框圆角 8px 偏大 | `--radius-sm: 6px` |
| 按钮阴影零散 rgba | 新增 `--shadow-accent` / `--shadow-danger` |
| 设置卡片 / 统计卡片 / 引导卡片阴影不一致 | 统一 `--shadow-xs` |
| 统计工具栏和卡片双重 margin | 在 settings-content 内重置 margin |

### 交互模式

| 交互 | 统一方案 |
|---|---|
| 删除待办 | `ConfirmDialog` |
| 清除全部数据 | `ConfirmDialog` |
| 保存设置 | Toast |
| 保存/删除待办 | Toast |
| 窗口加载 | `LoadingPane` |
| 加载失败 | `ErrorPane`（设置/宠物/气泡/引导） |
| 面板错误 | `Notice.notice-error` |
| 危险按钮 | `Button variant="danger"` |

### 文案

| 问题 | 修正 |
|---|---|
| `+ 添加待办` 风格不一致 | 去掉 `+`，用 Plus 图标 |
| 统计空状态写死“开始专注 25 分钟” | 改为“开始专注”，跟随实际设置 |
| 通用页提示“M1 接入位置持久化” | 改为用户可理解的“位置会自动保存。” |
| 关于页仍提 Kenney/占位素材 | 改为 Cute Girl Q 版角色 |
| 侧栏“M4 功能已解锁” | 改为“桌面陪伴 · 专注更轻松” |
| 危险/普通按钮层级混乱 | 清除数据 danger，退出普通 |

### 字体 / 数字输入

- 正文字号 13px 左右，卡片标题 14px，页面标题 20px。
- 数据统一 tabular numerals。
- 数字输入改为 `NumberInput`：
  - `− / +`
  - 单位内置
  - 隐藏原生 spinner
  - min/max clamp
- 设置页增加非常轻的暖色径向背景。
